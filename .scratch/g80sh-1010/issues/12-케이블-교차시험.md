# 12 — DP 케이블을 맞바꾸면 증상이 케이블을 따라가는가

Type: task
Status: resolved
Blocked by: —

## Question

**케이블은 이 추적에서 한 번도 검증된 적이 없다.** 11 의 "케이블 불량 아님" 논증에
구멍이 있다.

```
09-09 22:13  GPU DP 포트 교체
  사용자 확인: "모니터에 연결된 케이블은 그대로고, 그래픽카드 DP 포트 위치를 서로 바꿨다"

  → G80SH + G80SH 케이블  이 함께 다른 GPU 포트로 이동
  → 증상도 따라 이동

  배제되는 것: GPU 포트 불량, GPU 출력 불량
  배제 안 되는 것: 케이블  ← 모니터와 한 덩어리로 움직였다
```

11 은 이것을 "증상이 모니터를 따라 이동했다"로 읽고 케이블을 배제했지만,
**케이블도 같이 따라갔으므로 모니터와 케이블을 가르지 못한다.**

보고서 5장(160행) "케이블·포트·GPU 출력이 원인이 아님을 확정한다", 254행 표,
`_evidence\삼성제출_대장.md` 가 전부 같은 구멍을 공유한다.

## 왜 지금 중요한가

**PC 쪽 후보가 전부 소진된 상태에서 남은 미검증 물리 변수다.** 그리고 30초짜리다.

제출 측면에서도 급하다 — 삼성 상담의 첫 질문이 "케이블 바꿔보셨어요?"다.
지금 제출하면 **아니오**다.

기전상으로도 배제하기 어렵다. 증상의 핵심이 **EDID 확장 블록을 절전 중 안정적으로
못 읽는 것**인데, EDID 는 DP 보조 채널(AUX, 1Mbps 차동쌍)로 읽는다. 메인 링크
(4K240Hz + DSC, 대역폭 상한 근처)와 달리 AUX 는 케이블 품질이 나쁘면 조용히 불안정해진다.
**"화면은 멀쩡한데 EDID 만 못 읽는다"는 증상 모양이 AUX 채널 문제와 잘 맞는다.**

## 시험 방법

G50F(`SAM79DF`)는 같은 PC·같은 GPU·같은 드라이버에서 **11일간 276건**에 그친다.
그 케이블이 대조군이다.

```
1. G80SH 케이블과 G50F 케이블을 맞바꾼다 (모니터 쪽·GPU 쪽 둘 다)
   → G80SH 에 G50F 케이블,  G50F 에 G80SH 케이블
2. 교체 시각을 분 단위로 기록
3. 화면 끄고 관측
```

**판정 (이번엔 하루짜리로 충분하다)**

```
G80SH 가 계속 터진다  → 케이블 무관. 모니터 확정. 제출 근거가 깨끗해진다
G80SH 가 멎는다       → 케이블이다. 근원개선 경로가 열린다
G50F 가 터지기 시작   → 케이블이다. 가장 결정적인 형태
```

0건으로 효과를 주장하는 게 아니라 **폭풍이 어느 쪽을 따라가는지** 보는 것이므로
상시규칙 3 의 45% 함정에 걸리지 않는다. 기준선이 시간당 77~148 이라 한두 구간이면 갈린다.

### 이 배치로 판정되는 것 / 안 되는 것

```
판정됨   G80SH 가 계속 터진다  → 케이블 배제. 모니터 확정. 제출 근거가 깨끗해진다
         G80SH 가 멎는다       → 원래 G80SH 케이블이 범인. 근원개선 경로가 열린다

판정 안 됨  "폭풍이 케이블을 따라간다"는 역방향 확인.
            G50F 는 제3의 새 케이블이라 거기서 뭐가 나와도 귀속이 안 된다.
            원래 G80SH 케이블은 아무 데도 안 물려 있어 관측 대상에서 빠졌다.
```

### 부수 확인 — 대역폭은 변수가 아니다

G50F 케이블로 **3840x2160 @240Hz 가 그대로 섰다.** 4K240 은 DSC 가 필요한 구간이므로
이 케이블은 HBR3 급을 낸다. 12번 티켓이 걱정했던 "저사양 케이블이라 모드가 떨어진다"는
일어나지 않았다.

첫 시도에 G80SH 가 안 올라온 것은 장착 불량이었다(재장착으로 해결). 대역폭 문제가 아니다.

### 따라서

**케이블 배제. 이번엔 논증에 구멍이 없다.**

- 케이블은 물리적으로 교체됐고, 새 케이블은 **11일간 G50F 에서 276건**의 실적이 있다
- 증상은 모니터 쪽에 남았다. 케이블을 따라가지 않았다
- 대역폭도 아니다 — 새 케이블로 3840x2160@240Hz(DSC 구간)가 그대로 섰다
- AUX 채널 가설도 함께 기각된다. 다른 케이블의 AUX 로도 똑같이 못 읽는다

11 의 "케이블 불량 아님"은 **논증은 틀렸지만 결론은 맞았다.** 이제 근거가 제대로 붙었다.
