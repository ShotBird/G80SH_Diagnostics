## Question

공식 사용설명서(`source\BN81-29068D-02_WUG_..._KR_KOR_260727.0.pdf`)에
**모니터가 스스로 외부입력을 끊는 기능**이 명시돼 있다. 한 번도 확인한 적이 없다.

### p35 — 패널 보호 > 자동 연결 해제

```
자동 연결 해제
  화면 최적화 기능 사용 중에 외부입력을 해제할 수 있습니다.
  • 끄기 / 켜기
  ― S27HG80*S / S32HG80*S 모델만 지원합니다.
```

**대상 모델(S32HG802S)이 정확히 여기 해당한다.**

### p34 — 패널 보호

```
OLED 제품은 10분 동안 같은 정지 영상이 계속 표시되면 화면보호기 기능이
자동으로 실행되고, 픽셀을 보호하기 위해 화면보호기 기능은 끌 수 없습니다.
```

### p41 — 규격

```
입력 신호가 없으면 10분 이내에 절전 모드로 자동 전환됩니다.
```

## 왜 이게 유력한가 — 증상과 맞는 부분

| 관측 사실 | 「자동 연결 해제」로 설명되는가 |
|---|---|
| 화면이 꺼져 있는 동안에만 발생 (03) | ○ 패널 케어는 유휴/정지화면일 때 돈다 |
| EDID 를 아예 못 읽는 경우 1,339건 | ○ 입력을 끊으면 AUX 응답이 없다 |
| 오디오 엔드포인트가 같이 사라짐 (10) | ○ CTA 확장 블록을 못 읽으니 당연 |
| 모니터 쪽 알림(10011) 선행 0건 (02) | ○ HPD 를 제대로 안 내리고 조용히 빠지면 이렇게 보인다 |
| 드라이버가 먼저 재조회를 건다 (02) | ○ 알림 없이 사라지니 드라이버가 스스로 확인하러 간다 |
| 설치 당일부터 발생 (07) | ○ 공장 기본값이 '켜기'면 처음부터 그렇다 |
| PC 쪽 조치 전부 무효 (08·09·10·11·12) | ○ PC 가 관여하지 않는 모니터 내부 동작이므로 |

맵 「Not yet specified」의 **"'절전 전 상태'의 정체 — 펌웨어·패널 케어 동작이 후보이나
PC 에서 관측할 수단이 없다"** 가 바로 이것이다. **OSD 스위치로 존재한다.**

## 설명이 안 되는 부분 (그래서 확정이 아니다)

- **40~48초 주기로 몇 시간씩 반복**되는 것. 패널 케어는 보통 한 번 돌고 끝난다.
  다만 "끊음 → PC 가 재조회 → 다시 붙음 → 케어 재시작 → 다시 끊음" 의 루프라면
  이 파형이 나올 수 있다.
- **G50F 도 157건 있다.** G50F 는 OLED 가 아니므로 이 기능이 없다. 다른 원인이거나
  형제 devnode 동반 흔들림(12 의 부수 관측)일 것이다.
- 09-09 포트 교체 후 사흘 정지(11)를 이 가설로는 설명하기 어렵다.

## 확인 방법 — OSD 만 보면 된다

```
5-Way 버튼 → 메뉴 → 시스템(또는 패널 보호) → 자동 연결 해제
              현재 값이 '켜기' 인지 '끄기' 인지 확인
```

**켜기였다면** → 끄고 관측. 멎으면 원인 확정(그리고 불량이 아니라 설정).
**끄기였다면** → 이 가설 기각. 제출 진행. 오히려 근거가 하나 더 붙는다
("모니터가 입력을 끊는 기능은 꺼져 있는데도 끊긴다").

**어느 쪽이든 제출 전에 알아야 한다.**

## 같이 확인할 것 — 설명서에서 새로 나온 미시도 OSD 항목

| 항목 | 위치 | 설명서 |
|---|---|---|
| **DisplayPort 버전** | 시스템 | 사용할 DisplayPort 버전 선택. p33 |
| **DisplayPort DSC** | 시스템 | DSC 사용 여부. S32HG80\*S 전용. p33 |
| **VRR Control** | 시스템 | FreeSync 와 **별개** 항목. S32HG80\*S 지원. p35 |
| 절전 타이머 / 절전 꺼짐 예약 | 시스템 | 10~180분 자동 전원 꺼짐. p33 |
| 외부입력 자동 전환+ | 시스템 | 새 외부입력 자동 표시. p34 |
| 음량 | 시스템 | **OSD 에 음량 메뉴는 존재한다**. p33 |

`DisplayPort 버전`과 `DisplayPort DSC` 는 **링크 계층을 직접 바꾸는 스위치**인데
아직 한 번도 안 건드렸다. 09-3 의 주사율 변경(240→60Hz)과는 다른 축이다.

**단 변수는 하나씩**(상시규칙 4). 「자동 연결 해제」부터 확인하고, 그다음에 하나씩.

## 부수 — 오디오 의문 해소

- G80SH 에 **내장 스피커는 없다.** 연결 단자는 헤드폰(이어폰) 3극 TRS 하나뿐이다(p23).
- 그런데 **OSD 에 「음량」 메뉴는 있다**(p33). 헤드폰 출력 음량을 조절하는 것이다.
- p23: "HDMI-HDMI 또는 DP 케이블을 연결하여 **제품의 사운드가 활성화된 경우**,
  헤드폰을 연결하여 사용할 수 있습니다."
- p41: "**오디오 출력 사양은 연결된 기기의 음원 그대로 출력**됩니다."
  → 모니터는 오디오를 처리하지 않고 통과시킨다. EDID 의 LPCM 2채널 선언은 이 경로 때문.
