# 14 — DisplayPort DSC 를 끄면 멎는가

Type: task
Status: resolved
Blocked by: —

## Question

모니터 OSD 의 **시스템 > DisplayPort DSC** 를 [끄기]로 바꿨을 때 1010 반복이 멎는가.

설명서 p33 에서 확인한 항목이다.

```
DisplayPort DSC   DSC 기능의 사용 여부를 설정합니다.
                  ― S27HG80*S / S32HG80*S 모델만 지원합니다.
```

사용자가 **"끌 생각 없음"** 이라고 했다가 **실험 차원에서 껐다**(19:35 대화 기준).
제출은 이미 "정규 사양 그대로 쓰는데 발생한다"로 진술을 정리해 둔 상태이므로
이 시험 결과와 무관하게 제출 논리는 유지된다.

## 왜 볼 값어치가 있나

DSC 는 **링크 계층에서 픽셀 데이터를 압축**하는 기능이다. 증상의 핵심이
"절전 중 EDID(특히 CTA-861 확장 블록)를 안정적으로 못 읽는 것"인데,
EDID 는 메인 링크가 아니라 **AUX 보조 채널**로 읽으므로 DSC 와 직접 관계는 없다.

**그래서 기대는 낮다.** 다만 DSC 가 켜져 있으면 링크 훈련·재협상 절차 자체가 달라지고,
절전 진입/복귀 시 모니터 쪽 시퀀스도 달라진다. 배제 안 된 물리 변수가 이것뿐이다.

### 09-3 이 이미 봤다고 볼 수 없다

09-3 은 주사율 240→60Hz 로 DSC 를 우회하려 한 시험인데 **판정이 성립하지 않았다.**

```
60Hz    828초 → 0건
240Hz 1,112초 → 0건, 이후 재발
```

양쪽 다 침묵한 구간이라 **폭풍이 60Hz(DSC 없이)에서도 돈다는 것을 보인 적이 없다.**
30분 침묵은 원래 45% 확률이다(상시규칙 3). 이번이 이 축의 **첫 제대로 된 시험**이다.


### 전환 후 상태 (19:25 확인)

```
DISPLAY\SAM7B0C\...UID260   present OK   3840x2160 @240Hz   ← 모드 유지됐다
DISPLAY\SAM79DF\...UID256   present OK   2560x1440 @180Hz
EDID 제품코드                SAM7B0C 그대로. 새 프로파일 생성 없음
```

**4K240 이 그대로 섰다.** DP 2.1 UHBR13.5(RDNA4 지원) 대역폭이면 DSC 없이도
3840x2160@240Hz 8bpc 가 가능하므로 모순은 아니다.
**모드가 안 떨어졌으므로 해상도 변화라는 교란 변수가 없다 — 시험이 깨끗하다.**

FreeSync 와 달리 **DSC 전환은 EDID 제품코드를 바꾸지 않는다**(`7B0C` 유지).
새로 안 사실이다.

## 판정 기준

직전 기준선이 아주 강하다 — 바로 직전 구간에서 40~50초 간격으로 계속 돌고 있었다.

```
터진다        → 즉시 기각. DSC 는 무관
20분 이상 조용 → 의미는 있으나 확정 아님. 30분 0건은 원래 45% (상시규칙 3)
                 며칠 단위로 봐야 한다
```

**0건으로 효과를 주장하지 않는다.** 이 함정을 09-19 에만 다섯 번 밟았다.

**끈 쪽이 오히려 더 빨리, 더 자주 터졌다.** 주기와 `Default_Monitor` 강등 패턴도 동일하다.
기준선(시간당 77~148) 한가운데다.

### 따라서

**DSC 배제.** 그리고 이번엔 논증에 구멍이 없다.

- OSD 스위치로 직접 껐다(09-3 처럼 주사율로 우회한 게 아니다)
- **모드가 4K240 그대로 유지**돼서 해상도 교란 변수가 없다
- 변수는 이것 하나였다 — 케이블·포트·오디오·FreeSync·VRR 전부 그대로
- **0건이 아니라 폭풍 실재로 판정**했으므로 상시규칙 3 의 45% 함정에 안 걸린다

**09-3 이 못 한 판정을 이번에 했다.** DSC/대역폭 축이 "미판정"에서 "기각"으로 확정된다.

### 부수로 확인된 것

- **DSC 전환은 EDID 제품코드를 바꾸지 않는다**(`7B0C` 유지). FreeSync 와 다른 축이다.
- **DP 2.1 에서는 DSC 없이도 4K240 이 선다.** UHBR13.5 대역폭이 충분하다는 뜻이고,
  모니터가 DP 2.1 링크를 정상적으로 협상한다는 증거이기도 하다.
  → **"링크 자체는 멀쩡하다. 절전 중 EDID 만 못 내준다"**는 진술이 더 선명해진다.
- `SAM79DF`(G50F)가 19:27:22.218 에 동반 1건. 12 에서 본 형제 devnode 동반 흔들림과 같다.

다만 DP 2.1 에서는 DSC 없이도 4K240 이 서므로 켜든 끄든 실사용 차이는 없어 보인다.
