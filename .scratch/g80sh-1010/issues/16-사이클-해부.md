## Answer

### 1. 폭풍 한 사이클 = GPU 버스 조회 세 번

```
Q1   220 GPU  SAM7B0C 제거 -> Default_Monitor 추가     직전 5초 10011: 131/135 사이클에서 0건
      ↓ 0.23초 (중앙값)
Q2   220 GPU  Default_Monitor 제거                     직전에 10011 Type 9/10 약 30쌍
      ↓ 3.569초 (p10 3.534 ~ p90 3.586 — 거의 상수)
Q3   220 GPU  SAM7B0C 재추가                           직전에 10011 Type 1 ×6, 11, 6/7/8
      ↓ 수명 34~60초 — 이 구간 DxgKrnl 완전 무음 (131/135)
Q1   ...
```

- **Q1 은 링크 이벤트 없이 시작한다.** 02 의 판정을 135 사이클로 재확인했다.
- **Q1 에서 장치가 사라지지 않고 `Default_Monitor` 로 바뀐다.** 즉 그 순간 GPU 는
  "모니터가 아직 연결돼 있다"고 답하면서 **EDID 는 못 읽었다**. 연결이 끊기는 것(Q2)은 그 뒤다.
  → 순서는 **EDID 상실 → 0.2초 뒤 연결 상실 → 3.57초 뒤 재연결**이다.
- **Q2→Q3 의 3.569초는 흔들림이 ±0.03초다.** 재연결에 걸리는 고정 지연(HPD 재어설트 +
  링크 훈련 + EDID 읽기)이다.
- 부수: `Default_Monitor` 경유는 **09-20 17:04 포트 교체 이후 거의 모든 사이클**에 나타난다.
  그 전(09-19)에는 바로 제거됐다. 포트 교체로 devnode 가 `UID256`→`UID260` 으로 바뀐 것과
  시각이 겹친다(인과는 미판정).

### 2. "45~48초"는 하나의 주기가 아니다 — 하한 34초 + 약 9초 격자

수명(Q3 재추가 → 다음 Q1 제거) 135건:

```
min 34.2   p10 35.9   중앙값 39.0   p90 53.9   max 103.8

0.5초 히스토그램 — 봉우리가 줄지어 있다
  36.5~37.5   ████████████████████████████████████████████  (주 봉우리)
  41.0~42.0   (빈칸)
  45.0~45.5   ████████████████
  49.5~50.5   (빈칸)
  55.5~57.0   ██████
```

주 봉우리(36.8초)를 뺀 꼬리 60건이 36.8 + k×P 에 몰리는지 검정했다.

```
P = 8.0   정렬도 0.243
P = 8.5   정렬도 0.341
P = 9.0   정렬도 0.380   ← 최대
P = 9.5   정렬도 0.355
P = 10.0  정렬도 0.274
균등분포 대조(2만 회): p < 0.0001
```

→ **재연결 뒤 약 37초에 첫 "기회"가 오고, 거기서 넘기면 약 9초마다 다음 기회가 온다.**
기존 통계의 "평균 48.5초, 하한 37초"는 이 격자의 평균이었다.
**34.2초 아래로는 한 번도 없다** — 무작위 고장이 아니라 **타이머 구동**이다.

### 4. 주인은 아직 못 가른다 — 정직하게

격자의 기준점은 Q3(재연결)이고, 재연결은 PC 와 모니터가 **함께** 만드는 사건이다.
그래서 이 격자는 두 해석을 다 허용한다.

| 해석 | 이렇게 보인다 |
|---|---|
| **PC 쪽** — AMD 드라이버가 재연결 후 약 37초부터 약 9초 간격으로 EDID/DPCD 를 다시 확인하고, 절전 중 모니터가 응답을 못 하면 스스로 재열거를 건다 | 10011 없는 Q1 과 맞는다 |
| **모니터 쪽** — 모니터가 링크 수립 약 37초 뒤 절전 단계로 들어가며 약 9초 주기로 상태를 바꾸고, 그때 EDID 응답이 끊긴다(드라이버 안에서만 처리되는 IRQ_HPD 라면 10011 이 안 남는다) | 07(설치 당일부터)·08(드라이버 재설치 무효)·12·14·15(링크 구성 전부 무효)와 맞는다 |

**가르는 방법(하드웨어 불필요)**: `Kernel-PnP 810`(재열거 큐잉 =
`IoInvalidateDeviceRelations` 흔적, Q1 과 같은 밀리초)에 **스택 워크**를 건 캡처.
스택 최상단이 `amdkmdag` 의 타이머/DPC 경로면 PC 쪽 폴링, 인터럽트(ISR/DPC from HPD)
경로면 모니터 쪽 신호다. 상시 캡처 `G80SH ETW Auto` 를 바꾸는 일이라 **사용자 승인 후**
별도 티켓으로 한다.
