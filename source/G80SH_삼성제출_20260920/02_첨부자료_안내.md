### 요약 파일에서 보실 것

각 장치 제거(1010) 직전 구간의 이벤트 순서입니다.

```
증상 구간
  -38 ~ -62ms   Kernel-PnP 220    그래픽카드(PCI\VEN_1002&DEV_7550)의 자식 장치 재조회 시작
          0ms   Kernel-PnP 222    재조회 종료
          0ms   Kernel-PnP 1010   DISPLAY\SAM7B0C\... 제거
        +0.2s   Kernel-PnP 1010   DISPLAY\Default_Monitor\... 제거

  → 220 보다 앞선 DxgKrnl 10011(모니터 쪽 상태 변경 알림)이 0건입니다

정상 전환 구간 (baseline)
  -96 ~ -73ms   DxgKrnl 10011     20여 건   ← 모니터 쪽 알림이 먼저 옵니다
        -24ms   Kernel-PnP 220
          0ms   Kernel-PnP 1010
```

**순서가 정반대라는 점**이 이 자료의 핵심입니다.
