## 1. 요약

1. 화면이 꺼져 있는 동안 GPU 는 Windows 표준 런타임 전원 관리로 **절전(D3) ↔ 복귀(D0)**를 반복하고,
   복귀할 때마다 연결된 모든 디스플레이를 **재감지**한다.
2. G80SH 는 **연결 후 약 32.3초까지** 온 재감지는 통과하지만, **그 이후** 온 재감지에는 매번
   **1.39초 뒤 연결 해제**된다. 해제 3.57초 뒤 재연결되고, 다시 32초 뒤부터 같은 일이 반복된다(약 45초 주기).
3. 같은 GPU 의 **G50F 는 같은 재감지를 수백 회 모두 통과**했다.
4. GPU 복귀를 막으면 **30분간 0회**, 풀면 **27초 만에 재발**한다(A-B-A).
5. 32초 경계는 **PC 쪽 설정을 바꿔도 움직이지 않는다.**

→ 연결 후 약 32초에 진입하는 **모니터 절전 단계에서, 소스의 재감지(DP AUX/HPD)에 대한 응답**을 확인해 주십시오.

## 3. 한 사이클의 구조 (커널 추적, 135 사이클)

그래픽 드라이버가 Windows 에 보고한 연결 상태(`DdiQueryConnectionChange`, 대상 260 = G80SH):

```
T+0       G80SH "분리 → 즉시 연결" 보고 (0.1ms 간격)   → EDID 를 읽지 못해 Default_Monitor 로 교체
T+0.23s   G80SH "분리" 보고                            → 장치 제거
T+3.80s   G80SH "연결" 보고 (분리 후 3.569초 ±0.03)     → 정상 EDID 로 재인식
```

같은 시점 전 포트 보고에서 **G50F(대상 256)는 항상 "연결"**이다.

## 4. 재현 조건

### 4-1. 방아쇠 = GPU 절전 복귀 시의 재감지 (6/6, 이후 68/68)

```
GPU 절전(D3) 진입 → 0.1~0.5초 뒤 복귀(D0) → 약 60ms 뒤 전 포트 재감지 → (조건 충족 시) 1.39초 뒤 G80SH 해제
```

- 절전 진입: Windows 런타임 전원 관리의 유휴 타이머(`PopFxIdleTimeoutDpcRoutine`).
- 복귀: GPU 를 사용하는 아무 프로그램(화면 구성 조회, 센서 조회, 웹 브라우저의 그래픽 메모리 할당 등).
  상주 프로그램을 모두 종료해도 웹 브라우저가 복귀시켰다 — **특정 프로그램의 문제가 아니다.**
- 30분 측정: 절전 진입 68회 = 재감지 68회(1:1), 그중 39회가 해제.

### 4-2. 조건 = G80SH 가 연결된 뒤 약 32.3초가 지났을 것

재감지 191회(90분)의 결과, 재연결 후 경과 시간으로 완전히 갈린다.

```
재연결 후 26.4 ~ 32.1초에 온 재감지   → 전부 무사
재연결 후 32.5 ~ 73.2초에 온 재감지   → 전부 1.38~1.48초 뒤 해제 (113회, 중앙값 1.396초)
```

"재연결 후 몇 번째 재감지인가"로는 갈리지 않는다(32초를 넘겨 온 **첫** 재감지 51회가 전부 해제).

### 4-3. 32초 경계는 PC 설정으로 움직이지 않는다

AMD 드라이버의 초저전력 진입 지연 값(`PP_ULPSDelayIntervalInMilliSeconds`)을 30초 → 90초로 바꾸고 GPU 를 재시작해
30분 측정: **경계 그대로(32.1초 무사 / 32.5초 해제)**. 0.4초 폭의 고정 경계다.

### 4-4. 재감지를 없애면 증상도 없다 (A-B-A)

```
~05:51            평소               약 45초마다 해제
05:52 ~ 06:22     GPU 복귀 억제       GPU 절전 0회, 재감지 0회, 해제 0회 (30분)
06:22             억제 해제           27초 뒤 해제 재개 → 44초 간격으로 계속
```

### 4-5. 대조군

G50F 는 같은 GPU·같은 드라이버·같은 절전/복귀 순환에서 재감지 수백 회를 모두 "연결"로 통과했다.

## 7. 확인 요청 사항

1. **연결 후 약 32초에 진입하는 절전 단계**가 있는지, 그 단계에서 DP AUX 응답·HPD 동작이 어떻게 바뀌는지.
2. 그 단계에서 소스가 절전 복귀 후 재감지(DPCD/EDID 읽기)를 하면 **약 1.4초 뒤 연결 해제**가 일어나는지 —
   DP 소스가 주기적으로 절전·복귀하는 환경(AMD Radeon RX 9000 시리즈 등)에서 벤치 재현을 부탁드립니다.
3. 설치 당일부터 발생한 초기 불량이므로 **제품 교환**을 요청드립니다.
